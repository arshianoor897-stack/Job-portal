# 💼 HireHub – Job Portal

**HireHub** is a semester project prototype of an online job portal designed to connect employers with job seekers.

## 📌 Project Overview

This project demonstrates the frontend design and basic interactions of a job portal system.

## ✨ Current Features

- Login and Registration
- Admin Dashboard
- Employer Dashboard
- Job Seeker Dashboard
- Job Posting Interface
- Job Search and Filtering
- Job Application Tracking
- Company Approval Management

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

## 🚧 Project Status

**Frontend Demo – Work in Progress**

The current version is a frontend prototype. Flask backend integration and MySQL database connectivity are planned for future development.

## ▶️ How to Run

1. Download the project file.
2. Open `HireHub – Job Portal Demo.html` in a web browser.
3. Explore the demo interface.
